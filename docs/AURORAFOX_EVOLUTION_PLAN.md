# AuroraFox Evolution Engine

## Goal
Build a controlled improvement system as a separate development track.

## Principles
- No direct uncontrolled self-modification.
- Experiments happen in isolated branches/sandboxes.
- Every change must pass tests before acceptance.
- Keep full history and rollback capability.

## Initial modules
- Project analysis
- Improvement proposals
- Experiment manager
- Test runner
- Version tracking
- Safety policies
