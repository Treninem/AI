# AuroraFox File Intelligence

Локальная подсистема разбора файлов для существующего AuroraFox. Она не создаёт отдельный чат и не заменяет `AgentCore`: результат извлечения передаётся в обычный контекст сообщения или вызывается агентом как инструмент.

## Windows

`file_service.py` запускается только на `127.0.0.1:8767` и использует отдельное окружение `file_intelligence/.venv`.

Системный Python не требуется: `install_files.ps1` использует общий managed runtime AuroraFox из `runtime/ensure_uv.ps1`.

Реально обрабатываются:

- TXT/Markdown/JSON/CSV и исходный код;
- PDF: текстовый слой через pypdf; при недостатке текста возможен локальный визуальный fallback через PDFium + `qwen3-vl:8b`;
- DOCX, включая таблицы;
- XLSX/XLS с лимитами на количество ячеек;
- PPTX;
- ODT/ODS;
- изображения: метаданные + локальный vision/OCR через Ollama, если vision-модель доступна;
- аудио: локальная расшифровка через Aurora Voice;
- видео: встроенный ffmpeg из Python wheel, извлечение аудио и ограниченного числа кадров;
- ZIP/TAR/7Z: безопасный список содержимого и проверка потенциального path traversal;
- RAR принимается, но автоматическая распаковка отключена до подключения отдельного безопасного backend.

Основные лимиты по умолчанию:

- один файл: до 1 ГБ;
- текст в один AI-контекст: до 160000 символов;
- архив: до 5000 записей;
- заявленный распакованный размер: 512 МБ для безопасной автоматизации.

Результаты локального разбора кэшируются в пользовательском каталоге AuroraFox и очищаются из раздела настроек.

## Android

Android не запускает Python service. Базовый File Intelligence встроен непосредственно в `AuroraFoxRuntime`.

Native runtime умеет:

- читать обычный текст/код;
- извлекать текст из DOCX/PPTX/ODT/ODS;
- разбирать ячейки XLSX;
- проверять структуру PDF и количество страниц;
- читать метаданные изображений;
- использовать локальный Android STT для поддерживаемого аудио;
- читать метаданные видео;
- безопасно перечислять ZIP.

Текущий Android runtime **не выдаёт визуальный OCR как готовый**, если локальная mobile vision-модель не подключена. PDF через Android `PdfRenderer` подтверждает/рендерит структуру, но полноценное OCR содержимого пока не считается реализованным.

## Интеграция

Godot: `scripts/file_intelligence_client.gd`.

Вложения: `scripts/attachment_manager.gd`.

Агентные инструменты:

- `analyze_file`;
- `file_tree`;
- `search_file_cache` (Windows).

На Android `scripts/android_file_tool_bridge.gd` переопределяет файловые инструменты на native runtime.

## Приватность

Обработка локальная. Содержимое файлов не отправляется в облачный TTS/STT/vision сервис. При использовании vision анализ выполняется локальным Ollama на Windows. Извлечённый текст может храниться в локальном кэше AuroraFox до ручной/автоматической очистки.
