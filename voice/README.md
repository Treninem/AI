# AuroraFox Voice

Локальный голосовой модуль AuroraFox.

## Модели

### Озвучка (TTS)
- Silero `v5_5_ru`
- русский язык
- 48 kHz
- автоматические ударения, омографы и вопросительная интонация
- голос по умолчанию: `xenia`
- доступные голоса модели: `aidar`, `baya`, `kseniya`, `xenia`, `eugene`

Важно: обычные Silero TTS-модели, включая `v5_5_ru`, распространяются для некоммерческого использования по лицензии репозитория Silero. Если AuroraFox будет коммерческим продуктом, модель TTS нужно заменить на модель с подходящей коммерческой лицензией либо получить необходимые права.

### Распознавание речи (STT)
- OpenAI Whisper `large-v3-turbo`
- русский язык поддерживается официально
- MIT license
- автоматически использует CUDA при доступности

## Установка Windows

Запустить:

```powershell
powershell -ExecutionPolicy Bypass -File .\voice\install_voice.ps1
```

После установки AuroraFox сам запускает локальный voice-service на `127.0.0.1:8765`.
Модели скачиваются автоматически при первом обращении и затем используются из локального кэша.

## Работа

- `🎙 Голос` — начать запись; повторное нажатие завершает запись и отправляет её в Whisper.
- Распознанный русский текст попадает в поле сообщения.
- `🔊 Ответы: ВКЛ` — AuroraFox автоматически синтезирует и произносит новые ответы.
- Интернет для синтеза/распознавания после загрузки моделей не требуется.
